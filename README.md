## Why QMatSuite?

**QMatSuite** is a modern, scalable successor to the legacy **QuantumVITAS** platform, designed to meet today’s expectations for scientific software—both in usability and engineering quality.

### 🖥 Modern GUI, modern stack
QMatSuite is built on a **modern Electron-based GUI architecture**, the same class of technology used by professional tools such as **VS Code** and other widely adopted developer and scientific applications.

This replaces the legacy **JavaFX-based GUI**, enabling:
- Better performance and responsiveness
- Native cross-platform behavior
- Rapid UI iteration and long-term maintainability

### 🧩 Modular & maintainable by design
QMatSuite adopts a **modular software architecture**, with a clear separation between:
- core computation logic
- workflows and automation
- GUI and user interaction

This makes the codebase **scalable, maintainable, and future-proof**, rather than a monolithic application that becomes difficult to extend.

### ⚙️ New infrastructure: ready-to-use Quantum ESPRESSO
QMatSuite introduces a new infrastructure providing:
- **Up-to-date, high-performance Quantum ESPRESSO executables**
- Fully built, tested, and ready to use
- All-in-one distribution, eliminating common installation and compilation barriers

This infrastructure is designed to work seamlessly with the QMatSuite GUI and workflow system.
